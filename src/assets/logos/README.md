# Restaurant logos

Put logo files here, named after the restaurant's `logoKey` in `src/data/restaurants.ts`:

- `dunkin.svg` (or `.png` / `.jpg` / `.webp`) for Dunkin' Donuts
- `paul.svg` (or `.png` / `.jpg` / `.webp`) for PAUL

They're picked up automatically, with no code changes. A square image with a transparent or white background looks best.
Any restaurant without a file shows an initials badge.

Get the official files from each brand's website or press/media kit.

# AfterBite

**Save food. Save money. Make a difference.**

AfterBite is a frontend-only prototype of an evening food-saving marketplace for Morocco. From 8 PM each evening, restaurants list their unsold fresh food at a discount, and customers reserve it and collect it before closing.

> University Shark Tank prototype. All restaurants, offers, locations and statistics are fictional demonstration data. There is no backend, and no payments are processed.

## Tech stack
React 18, TypeScript, Vite 5, Tailwind CSS 3 and lucide-react. All data is persisted in LocalStorage.

## Getting started
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build
npm run preview    # serve the production build
```

## Presenting
Before a live demo, use **Footer → Reset demo data**. This clears favorites, reservations and partner applications, and restores every offer's original stock.
